# Group Project 1 — Spoken Numbers Recognition Challenge

## Часть 1. Обучение

В качестве базовой модели была использована реализация подхода CRNN-CTC.  
На основе аудиосигнала формировались мел-спектрограммы фиксированного размера `(80 × 320)`, которые интерпретировались 
как одноканальные изображения и подавались на вход сверточного бэкбона на базе ResNet18.

Поверх сверточной части был добавлен рекуррентный слой (GRU), а также классификационная голова размерности `(40, 11)`.  
Модель предсказывает последовательности, состоящие из цифр `0–9` и специального символа пропуска (blank), используемого в CTC.

В качестве аугментаций применялись:
- добавление шума к аудиосигналу,
- случайная временная маска,
- случайная частотная маска.

Количество параметров модели **1.133 млн**.

---

## Часть 2. Результаты

Обучение проводилось в постановке с непересекающимися спикерами.  
В качестве валидационного множества был выбран спикер `spk_D`.

В качестве функции потерь использовалась `nn.CTCLoss` (PyTorch),  
метрика качества - простая accuracy, общая реализация реализация приведена в `kaggle.ipynb`.

Лучшие результаты на валидации:
- `best_val_acc = 0.9660`
- `CER ≈ 0.63%`

На финальной выборке соревнования были получены следующие значения:
- **скрытая часть**: `4.067`
- **открытая часть**: `3.818`

Ноутбук с финальным предиктом:
https://www.kaggle.com/code/manzhuradmitrii/manzhura-asr-2026/edit

## Часть 3. Выводы

Основные выводы:

- Сверточные нейронные сети, применённые к мел-спектрограммам, эффективно извлекают признаки, пригодные для задачи распознавания речи.

- Даже при использовании относительно простой архитектуры (ResNet18 + GRU + CTC) удаётся достичь высокого качества.

- Отсутствие продвинутых методов (beam search, языковая модель, посимвольное декодирование с постобработкой) не помешало получить конкурентные результаты.

- Базовые аугментации (шум, временные и частотные маски) оказываются достаточными для обеспечения устойчивости модели.

- При сравнительно небольшом числе параметров модель демонстрирует хорошую обобщающую способность.

Потенциальные направления улучшения:

- использование beam search при декодировании,
- добавление языковой модели,
- переход к посимвольному предсказанию с последующей постобработкой,
- более качестванная настройка гиперпараметров и архитектуры.
